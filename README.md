# access_food
Задача для AI/ML инженера по разработке системы генерации рационов питания с использованием RAG и LangChain.

Цель: Разработать функционал генерации рационов питания на 4 дня с возможностью формирования списка продуктов питания, используя актуальные данные о доступных продуктах у поставщиков с доставкой на дом. Система должна минимизировать ошибки и "галлюцинации" модели, обеспечивая точность и актуальность предложений.

Основные этапы задачи:
1.	Сбор данных:
o	Цель: Автоматически собрать данные о продуктах с сайта ритейлера Пятерочки через сайт Купер: https://kuper.ru/5ka  (названия, описания, цены, категории, доступность).
o	Ожидания: Система должна обновлять данные ежедневно, обеспечивая актуальность информации.
o	Предпочтительные инструменты: Python (BeautifulSoup, Scrapy), API ритейлеров (если доступно).
2.	Обработка данных:
o	Цель: Подготовить данные для векторизации и последующего использования в системе генерации.
o	Ожидания: Данные должны быть очищены, нормализованы и структурированы для использования в модели.
o	Предпочтительные инструменты: Pandas, NumPy.
3.	Построение эмбеддингов:
o	Цель: Векторизировать данные о продуктах для их эффективного использования в RAG.
o	Ожидания: Создать эмбеддинги, которые обеспечат быстрый и точный поиск релевантных данных.
o	Предпочтительные инструменты: BERT, Sentence Transformers.
4.	Интеграция RAG и LangChain:
o	Цель: Настроить систему RAG для извлечения данных из базы эмбеддингов и интеграции с LangChain для генерации рационов.
o	Ожидания: Система должна точно формировать запросы к модели, используя актуальные данные.
o	Предпочтительные инструменты: langchain, Faiss, Pinecone.
5.	Генерация рационов и списков продуктов:
o	Цель: Разработать алгоритм, который генерирует рацион питания и список продуктов на основе доступных данных.
o	Ожидания: Рационы должны учитывать пищевые предпочтения и ограничения пользователей.
o	Предпочтительные инструменты: OpenAI API (ChatGPT), LangChain.
6.	Тестирование и оптимизация:
o	Цель: Провести тестирование на выборке пользователей, измеряя основные метрики.
o	Метрики успеха:
	Точность предложений (насколько рацион соответствует доступным продуктам).
	Удовлетворенность пользователей (оценка пользователей, использующих предложенные рационы).
	Обновляемость данных (актуальность предложенных продуктов).
	Время генерации (скорость формирования рационов и списков покупок).
